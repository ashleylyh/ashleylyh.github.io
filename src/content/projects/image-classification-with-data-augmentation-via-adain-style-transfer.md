Assignment in the Machine Learning course focused on leveraging CNN-based generative models to improve image classification through synthetic data augmentation using AdaIN style transfer.

## Key Technology & Contributions

- Implemented the AdaIN style transfer model to generate synthetic samples across diverse visual domains.
- Augmented the training dataset with generated data, achieving a 12% improvement in classification accuracy compared to the baseline.
- Validated the approach by demonstrating improved model generalization and reduced overfitting through generative augmentation.
