An AI-powered web game that challenges players to outdraw an AI opponent by sketching objects as quickly and accurately as possible, designed for 2025 Academia Sinica Open House event.

The game leverage WebSocket, real-time pretrained CNN inference, a FastAPI + Redis backend, QRcode generate certificate delivery, education purposed feature map using UMAP for visualizations, and a live update Streamlit dashboard.

Provide an engaging and interactive experience.

## Key Technology & Contributions

- Engineered a responsive multiplayer drawing game frontend with WebSocket integration, enabling real-time sketch input, CNN-based inference, live predicted probability updates, and instant certificate generation across multiple players.
- Developed a scalable Python FastAPI backend with Redis, supporting high-throughput real-time data transmission and storage/retrieval; Implemented QR code generation for on-demand certificate downloads and integrated UMAP dimensionality reduction to visualize player drawing clusters against training datasets.
- Created an interactive Streamlit dashboard with live statistical data visualization, dynamic player rankings, and real-time performance analytics, enhancing audience engagement during public screening.
