Project in the Computer Organization course focused on implementing a simplified version of Tetris entirely in MIPS assembly, demonstrating low-level programming, system calls, and real-time game logic execution.

## Key Technology & Contributions

- Implemented core Tetris mechanics (block movement, rotation, collision detection, and row clearing) in MIPS, ensuring 100% compliance with game rules while maintaining real-time responsiveness.
- Optimized the game loop and memory structures to handle a 10×23 grid, reducing invalid moves and improving block update efficiency.
